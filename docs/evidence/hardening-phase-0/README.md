# Hardening Phase 0 Evidence

Store objective evidence for Phase 0 completion in this folder.

## Subfolders

- `global/` — ownership approvals, policy sign-offs, meeting notes
- `gcp/` — cloud-specific evidence for GCP
- `aws/` — cloud-specific evidence for AWS
- `azure/` — cloud-specific evidence for Azure

## Naming Convention

Use: `YYYY-MM-DD_<topic>_<owner>.md|pdf|png|txt`

Examples:

- `2026-02-26_owner-assignments_platformlead.md`
- `2026-02-27_environment-policy-approval_securitylead.pdf`
- `2026-02-27_tracker-export_opslead.csv`
