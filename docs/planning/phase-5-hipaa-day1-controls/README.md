# Phase 5 — HIPAA Day-1 Controls

This folder operationalizes Phase 5 from [implementation-plan.MD](../../../implementation-plan.MD).

It provides practical artifacts for executing and evidencing HIPAA day-1 safeguards for the Anonymization & Exchange Gateway for Imaging Studies (AEGIS).

## Included Artifacts

- `hipaa-day1-control-checklist.md` — control-by-control execution checklist.
- `privileged-access-review-template.md` — monthly access review record.
- `security-training-attestation-template.md` — workforce security training evidence.
- `incident-tabletop-record-template.md` — tabletop/live drill capture form.
- `secret-rotation-execution-record-template.md` — secret rotation execution evidence.

## Completion Criteria

Phase 5 is complete when checklist items are filled with owner/date/evidence references and approved by Security + Compliance.
