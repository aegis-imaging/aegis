# Security Testing Cadence (Phase 8)

## Cadence

- Weekly automated baseline checks (`security-cadence.yml`).
- Weekly compliance snapshot generation (`compliance-snapshot.yml`).
- Quarterly threat-model review and remediation planning.

## Automated outputs

- Guardrail check pass/fail artifacts
- Go/Node/Python dependency snapshots
- Consolidated compliance snapshot report

## Ownership

- Security Lead: owns cadence and review outcomes
- Platform Lead: owns remediation delivery for platform findings
- Compliance Lead: validates evidence retention
