# Access Matrix — Project/Site Scoping (Phase 0)

## Purpose
Canonical access matrix for authenticated API routes in `api/main.go`.

## Access Categories
- `public`: No authenticated context required.
- `platform_admin`: Platform-level admin/global owner only.
- `project_member_any`: Authenticated project member access (with project scoping where applicable).
- `project_member_site_scoped`: Site roles are institution-scoped (`study.institution_id` match required).
- `project_owner_only`: Reserved for project-owner capability migrations in Phase 2.

## Data Scope Rule
- Site-scoped roles (`site_coordinator`, `site_viewer`) must only access studies where `institution_id` maps to their site membership.
- Coordinating roles (`owner`, `coordinator`, `reviewer`) can access full project datasets.
- Platform `admin` keeps global cross-project visibility.
