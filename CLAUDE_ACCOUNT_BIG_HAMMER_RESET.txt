Claude Code Account Reset ("Big Hammer")
=======================================

Goal
----
Force VS Code Claude auth to stop using your personal account and re-authenticate with:
  ai@aegisimaging.ai

Step 1: Hard close everything
-----------------------------
1) Quit VS Code completely.
2) Quit all browsers completely (all profiles/windows).

Step 2: Remove Claude auth state from VS Code user data
--------------------------------------------------------
Run in Terminal:

mkdir -p ~/Desktop/vscode-claude-backup-$(date +%Y%m%d-%H%M%S)
BACKUP=$(ls -dt ~/Desktop/vscode-claude-backup-* | head -1)

find ~/Library/Application\ Support/Code/User -iname "*claude*" -o -iname "*anthropic*" | while read p; do
  mkdir -p "$BACKUP$(dirname "$p" | sed "s|$HOME||")"
  mv "$p" "$BACKUP$(echo "$p" | sed "s|$HOME||")"
done

Notes:
- This moves matching Claude/Anthropic files to a timestamped desktop backup folder.
- Nothing is deleted permanently in this step.

Step 3: Remove saved credentials from macOS Keychain
-----------------------------------------------------
1) Open "Keychain Access".
2) Search and delete items containing:
   - claude
   - anthropic
   - VS Code auth entries tied to Claude login

Step 4: Browser isolation
-------------------------
1) Use a browser/profile you do NOT use for personal Claude.
2) Sign in only as ai@aegisimaging.ai at https://claude.ai
3) Keep personal Claude signed out everywhere.

Step 5: Re-auth in VS Code AEGIS profile
-----------------------------------------
1) Open VS Code with the AEGIS profile.
2) Reinstall Claude extension (if removed).
3) Start Claude sign-in from VS Code.
4) Complete auth in the browser session already signed in as ai@aegisimaging.ai.

If it still auto-logs personal account
--------------------------------------
Create a separate macOS user account (e.g., "AEGIS") and run VS Code there.
That gives full OS-level session isolation and is the guaranteed fallback.
