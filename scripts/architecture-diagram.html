Sending Sources (External Browser + Internal Enterprise)

React Upload Portal (Web)

  • DICOM file picker
  • Client-side parsing (dcmjs)
  • Tag anonymization preview (before/after)
  • Optional email for notifications
  • Project & profile selection
  • Per-file progress + retry (3× backoff)

De-identification Engine (@aegis/client)

  • DICOM PS3.15 Annex E Basic Profile
  • 18 HIPAA Safe Harbor identifiers
  • Per-project retained tags (anon profiles)
  • StudyInstanceUID regeneration
  • Runs in browser — PHI never leaves hospital

Batch Import CLI (Go)

  • Server-side DICOM parsing (suyashkumar/dicom)
  • Recursive directory scan
  • Groups files by StudyInstanceUID
  • Dry-run mode for preview
  • Duplicate detection (safe re-run)

Key Principle

  • PHI is stripped in the browser BEFORE data leaves the hospital network
  • Only tag-de-identified DICOM is transmitted over HTTPS
  • No software installation required at sending sites
  • Batch import assumes pre-de-identified data

Classification

Protocol Compliance

React Admin Dashboard (Web)

  • OHIF Viewer integration (embedded iframe + new tab)

Authentication & Security

  • Multi-provider auth middleware (auto-detect)
  • GCP: Identity-Aware Proxy (IAP)
  • AWS: ALB + Cognito (JWT)
  • Azure: AD Easy Auth
  • Dev: auto-auth via DEV_USER_EMAIL
  • RBAC: RequireAuth / RequireRole("admin")
  • CORS, rate limiting, TLS 1.3

Routing Rules Engine

  • Conditions: project, modality, body part, source
  • Actions: require_defacing, require_phi_scan, require_qc_check, require_bids_conversion, require_classification, require_protocol_check
  • auto_approve, reject, route_to destination
  • Priority-ordered, all matching rules fire
  • Re-evaluation after classification
